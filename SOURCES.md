# Источники и авторство

Это сборный пакет дополнений. Переводы сообщества не выдаются за полностью написанные заново. Источник каждой изменённой строки сохранён в changes.json в data/.

## Источники

- [vvmax/translates](https://github.com/vvmax/translates), снимок 11e3dae9365e5762b2320bd9acc94430c456eaa2. Для Botania предпочтён файл под старую версию; Magical Crops существенно переработан.
- [GTNH-Translations](https://github.com/GTNewHorizons/GTNH-Translations): переводы сообщества, сопоставленные по ключам установленной сборки. Это не перенос игровых изменений GTNH.
- [Immersive Engineering](https://github.com/BluSunrize/ImmersiveEngineering): официальные языковые файлы. Из ветки 1.10.2 автоматически переносились только строки с идентичным английским текстом.
- [SlavkaCool](https://gist.github.com/SlavkaCool): переводы для DivineRPG 1.4.1.4, Extra Cells 2.3.14, Draconic Evolution 1.0.2h и Botania r1.8-249.
- Исходные русские файлы установленных модов сохраняются; заменяются только дополнения и исправленные строки.
