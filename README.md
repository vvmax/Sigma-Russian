# Sigma Russian — Minecraft 1.7.10

Русский ресурс-пак для сборки Sigma на Forge 1.7.10: переводы названий, интерфейсов, описаний и руководств модов. Включает 83 раздела руководства Draconic Evolution и 41 страницу wiki Extra Cells.

## Скачать и установить

- [Sigma-Russian.zip](https://github.com/vvmax/Sigma-Russian/raw/refs/heads/main/Sigma-Russian.zip) — основной ресурс-пак. Поместите в `resourcepacks` своего профиля, включите выше других переводов и выберите «Русский (Россия)».
- [Sigma-Russian-complete.zip](https://github.com/vvmax/Sigma-Russian/raw/refs/heads/main/Sigma-Russian-complete.zip) — полный комплект с клиентским дополнением, установщиком IC2 и документацией.
- [SigmaRussian-Tooltips-1.7.10-1.0.0.jar](https://github.com/vvmax/Sigma-Russian/raw/refs/heads/main/SigmaRussian-Tooltips-1.7.10-1.0.0.jar) — дополнение для зашитых в код подсказок DivineRPG. Положите в `mods` **только клиента**.

После установки полностью перезапустите Minecraft: это также сбросит кэш руководства Draconic Evolution. Сервер менять не требуется. Основной ресурс-пак не изменяет JAR модов.

## IC2

В используемой версии IC2 ресурс-пак не переопределяет встроенную таблицу перевода. Для него есть отдельный необязательный установщик. Закройте игру и выполните из распакованного полного комплекта:

```powershell
python install_ic2.py --instance "D:\Minecraft\Instances\Sigma" --pack Sigma-Russian.zip
```

Замените путь своим. Установщик проверяет SHA-256 исходного JAR, заменяет только `ic2/lang/ru_RU.properties` и сохраняет резервную копию в `backups/sigma-russian/` профиля. При несовпадении версии останавливается без изменений. Для отката верните JAR из резервной копии.

## Исходники и проверка

В архиве `Sigma-Russian-sources.zip`: `resourcepack/` — редактируемые ресурсы; `tooltip-fix/` — Java-исходники дополнения и тесты; `data/changes.json` — происхождение изменённых строк. `build_release.py` собирает архивы стандартным Python 3 без сторонних зависимостей.

Проверены покрытие языковых ключей установленной сборки, подстановки, кодировка, дубликаты и ресурсные ссылки; выборочно — смысл, числа и механики. Это не означает, что весь текст вычитан или проверен в игре. Дополнение подсказок прошло 11 тестов на Java 8; отображение после перезапуска клиента ещё требует проверки. Английский текст может оставаться в изображениях, сторонних заданиях и других строках внутри кода.
